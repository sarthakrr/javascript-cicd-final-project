# JavaScript CI/CD Final Project

## Project Overview

This project demonstrates Continuous Integration and Continuous Delivery (CI/CD) using JavaScript.

## Technologies Used
- JavaScript
- GitHub Actions
- Tekton
- OpenShift

## Project Objectives
1. Automate linting using GitHub Actions.
2. Perform unit testing.
3. Create Tekton tasks for linting, testing and building an image.
4. Create an OpenShift CI/CD pipeline.
5. Deploy the application to OpenShift.
